# LIFEFORM

**Build a living creature. Leave a lineage.**

A playable evolutionary sandbox that continues from a primitive organism through societies, industry, and interplanetary life. It runs locally in a browser, with a deterministic TypeScript simulation, Canvas 2D organisms, touch controls, and no backend or account.

## Run

Use Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

Open **http://127.0.0.1:5173**. For a production build:

```sh
npm run build
npm run preview
```

The static site is in `dist/`; serve it over HTTP. Fonts and all runtime assets are local. Creature animation and audio are generated by the app; original habitat artwork is bundled locally. See the [visual design notes](docs/VISUAL_DESIGN.md).

## Play

| Input                          | Action                               |
| ------------------------------ | ------------------------------------ |
| WASD / arrows / touch joystick | Move                                 |
| Click or tap the habitat       | Move to a destination                |
| Space / bite button            | Eat compatible food or attack        |
| Shift / lightning button       | Sprint using stamina                 |
| R / Reproduce                  | Create offspring when mature and fed |
| P / pause button               | Pause or resume                      |
| 1x / 2x / 4x                   | Change simulation speed              |

Settings includes control remapping, sound, vibration on supported devices, reduced motion, particles, larger text, and left-handed touch controls. Hybrid mode eats nearby food automatically. Menus and hidden tabs pause time; return to Habitat to progress construction, research and expeditions.

Follow **Your next move** to eat, evolve, and reproduce. **Move to food** marks a compatible meal and moves your creature toward it. **Evolve** opens three suggested adaptations, with costs and a preview before purchase; the full adaptation library remains available. The habitat fills the play area, with compact creature status, quest checkpoints, a world map and an action dock. On phones, the current quest appears above the habitat and touch controls.

Creature contains organ previews, the body editor, inherited genes, mating, behavioral traits and procedural variations. Extra stats and habitat analysis expand on demand. Lineage contains the family archive, species branches and nests. The map reveals habitats and investigation sites. Discoveries contains renewable ecological objectives and unlocked starting paths.

Open **Explore all adaptations → Explore the evolution tree** to plan a biological goal. Connected prerequisites show remaining point/biomass costs and body conflicts without spending resources. Individual previews compare stats, food sources, and travel/exposure across habitats. **Lineage → Explore the species tree** opens connected species ancestry, founding bodies, descendant populations and recovered fossils. Recovered fossil sites can be revisited in the habitat.

To reach intelligence, evolve a light-sensitive eye, associative brain, legs and manipulating digits. Vocal language and social memory lead to society. Gather materials, research tools, establish three living relatives, and found a settlement. Assign professions and secure food, water and housing before expanding. The same organism remains playable throughout.

Research construction, writing, agriculture or aquaculture, trade, metallurgy and energy. Factories and scientific institutes lead to rocketry. Space exploration in Society supports orbit, surveys, mining, colonies, supplies, habitat engineering, additional star systems, and repeatable research. Offspring, settlement citizens and off-world descendants can continue a surviving lineage.

## Implemented systems

- Six connected biomes with seed-dependent placement, terrain relief, moisture and rivers; environmental tolerances, exploration sites and ten pressure templates with generated severity.
- Thirty organs, fifty authored mutations, procedural inherited variations, twelve behavioral specializations, five genetic loci, mating and asexual reproduction.
- Ten wildlife archetypes, fifteen ecological resources, food webs, spatial AI, near/far populations, regional accounting, natural selection, diseases, status effects, symbiosis and a rare apex encounter.
- Species splitting, extinction fossils, family and species ancestry, legacy archives, six starting organisms, eleven world-rule choices and renewable objectives.
- Learning, remembered locations, eight tools, eleven professions, twenty-one buildings, twenty-seven technologies, settlement growth/collapse, agriculture, industry, economy, trade, conflict, government and history-derived culture.
- Orbital habitats, generated planets and alien-life records, mining, colonies with biological suitability, resupply, habitat engineering and repeatable frontiers.
- Versioned local saves, recovery backup, JSON import/export and migration from schemas 1 through 6 to schema 7.

This is the smallest playable implementation across the brief's progression, with aggregate settlements and expedition-based space exploration. The detailed [coverage ledger](docs/IMPLEMENTATION.md) distinguishes implemented mechanics from optional live-service features, long-term content targets and release validation.

## Save your lineage

Autosaves run during active play and after important actions. Export a save from Settings for a durable copy. Starting another world retains discoveries, unlocked starting paths, legacy marks, settings and earlier lineage archives. Corrupt saves are validated before replacement; a valid backup can recover a damaged primary save. Saves are bounded to 8 MB and browser storage may fill sooner.

## Verify and tune

```sh
npm test                     # Simulation, biology, society, space, saves and replay
npm run build                # Strict TypeScript and production bundle
npx playwright install chromium
npm run test:browser         # Desktop and mobile interaction regressions
npm run test:production      # Requires npm run preview on port 4173
npm run profile              # Ten-minute headless benchmark
npm run balance              # 24 seeded two-minute automated play scenarios
npm run format:check
```

Development tools in the footer show population fitness, births, deaths and simulation timing. Useful commands:

```text
/points 20
/biomass 100
/mutation jointed-legs
/reproduce
/teleport forest
/event winter
/disease marsh-fever
/speciate Velari terra
/nest
/material wood 100
/knowledge 100
/advance 30
/die
/population stalker 4
```

Aliases include `/add mutation ID`, `/set energy N`, `/set population ID N`, `/trigger drought`, `/trigger disease ID`, `/trigger extinction`, and forward-only `/set time N`. `window.lifeform.snapshot()`, `.command(text)` and `.metrics()` exist only in development. No analytics leave the browser.
